# Silicon Nights V2 — ASEM Digital IC Design Learning Hub

## Update your existing GitHub / Netlify site
1. Open your GitHub repository.
2. Open `index.html` and choose Edit (pencil).
3. Select all existing code and replace it with the complete contents of this new `index.html`.
4. Commit the change. Netlify should automatically redeploy if the repository is connected.

Alternatively, upload this whole folder to a new repository and connect it to Netlify.

## Features
- Pink, navy, purple and white visual theme.
- Animated, lightweight canvas particles with subtle connection lines.
- Tab-based navigation; no single long scrolling lesson page.
- Five workshop days with six submodules each.
- Clickable jargon terms throughout lessons.
- Ten questions per day (50 total), with objective and short-answer questions.
- Short-answer keyword feedback and guided model answers.
- Local study chatbot that answers from this guide and glossary. It is not a live AI model and does not send data to an external service.
- Local progress tracking and learning journal using browser localStorage.
- Responsive layout for desktop and mobile.

## Notes
Progress and notes are stored in the browser on the device where you use the site. They do not sync across devices. Export journal notes for a backup.
This is an independent learning companion, not official ASEM course material. Always follow ASEM instructions for tool setup, exact commands and lab procedures.
